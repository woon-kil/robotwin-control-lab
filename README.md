# RoboTwin Control Lab

Status:
P-000A.1 — Requirements Amendment

Current Gate:
P-000A.1 Requirements Amendment

RoboTwin Control Lab is an industrial robot Digital Twin and Pre-Execution Validation platform designed to verify whether a robot task can be executed safely and accurately before controller execution.
핵심 질문은 컨트롤러에 명령을 전달하기 전에 로봇이 그 작업을 안전하고 정확하게 수행할 수 있는가이다.
P-000A의 REQ-001~REQ-018과 NFR-001~NFR-007은 유지하고, Workcell, Task-Level Command, Pre-Execution Validation, Safety Zone을 추가한다.
Golden Reference 후보는 UR10e 계열이며 소스와 버전은 확정하지 않았다. Hazardous Filter Handling Simulation은 독점 로봇의 복제가 아니다.
구현은 시작하지 않았다. 진단과 정비 판단은 Maintenance-Agentic-Twin의 책임이다.
